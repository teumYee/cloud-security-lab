# Cloud Security Lab

클라우드 환경의 네트워크 및 보안 구조를 직접 구축하고
취약점이 발생하는 과정을 이해하기 위한 개인 실습 프로젝트입니다.

## Goal

- 네트워크 및 Linux 기초 학습
- AWS VPC 기반 네트워크 구성
- Public / Private Subnet 분리
- Web / DB 서버 구축 및 접근제어
- 취약 웹 애플리케이션 구축
- 웹 취약점 분석 및 보안진단
- 실습 과정 및 트러블슈팅 문서화
